# Raw data (not committed)

Download the *splotchy face* files from Dryad and place them in this folder:

<https://doi.org/10.5061/dryad.fxpnvx15q> - *Data from: Structural and epistatic regulatory variants cause hallmark white spotting in cattle* (Dryad, version of 8 Oct 2025).

| File | Content |
|---|---|
| `splotchy_GWAS_geno_set.bed` / `.bim` / `.fam` | PLINK binary genotypes: 128 animals, 41,534 SNPs |
| `splotchy_phenos.txt` | Phenotype (`FID IID Splotchy`; coded 0 = control, 1 = case in the analysis) |

The Dryad package also contains the *speckled coat* files, which are not used here. Check the licence shown on the Dryad
record before redistributing any data file. SHA-256 checksums of the files used are in `../CHECKSUMS.sha256`.

Data were generated and released by the authors of Jivanji *et al.* (2025), *Science Advances* 11(46):eadt5913,
doi:10.1126/sciadv.adt5913 - please cite that paper and the dataset when using them.
